# Eatsii

Eatsii is a Jakarta, Indonesia based foodtech startup operating a cloud kitchen platform. It runs a cloud kitchen concept that offers takeaway and delivery alongside dine-in service, and markets cloud kitchen space to F&B operators under a franchise partnership model — positioning itself as helping food and beverage companies run a more efficient kitchen in the food delivery era.

- Website: https://eatsii.com (not serving a live site as of 2026-07-20)
- LinkedIn: https://www.linkedin.com/company/eatsii
- Instagram: https://www.instagram.com/eatsii/
- Backed by: 500 Global (500 Durians)
- Size: 11-50 employees, Food and Beverage Services

## API surface

None. Eatsii publishes no developer portal, public API, documentation, SDKs, or specifications.
